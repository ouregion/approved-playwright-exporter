# Provenance and extraction boundary

This slice is based on the owner's personal staged browser-testing prototype. The generic contracts module was copied from that project. The assembler was narrowed and rewritten around the original approved-plan/hash-selection pattern.

New work in this export: an explicit template allowlist; a working independent validator CLI; plan revision checks; a fixed synthetic HTML fixture and assertion-bearing spec; a tamper-and-restore demo; and focused package tests. These additions do not establish that the original application's full workflow is integrated.

No original history, company branding, site URLs, model configuration, login state, historical generated code or test artifacts were copied. Package-manager registry URLs and dependency integrity hashes in the generated suite lockfile are public dependency metadata.

The owner confirmed that this is personal project work. No release license was present in the source root. The owner has selected MIT for the extracted personal code and new additions; see `LICENSE`. This does not replace the licenses or notices of third-party dependencies.
